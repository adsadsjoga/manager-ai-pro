# Pendencias para quando tivermos dominio

Este bloco fica guardado para a fase de venda/publicacao do Ads Manager AI Pro.

## Da para fazer sem dominio comprado

- Colocar o app online usando URL gratis da hospedagem, como uma URL temporaria da Vercel.
- Testar login, dashboard, clientes, billing, relatorios, Meta, Stripe/Payhip e Shopify em ambiente online.
- Usar Clerk com a URL temporaria da hospedagem.
- Usar Stripe em modo teste ou producao com a URL temporaria.
- Criar onboarding, area de clientes, configuracoes, planos e limites.
- Continuar melhorando IA, relatorios, criativos, recomendacoes e CRM.
- Conectar Shopify com uma loja real usando token privado, sem precisar comprar dominio para o nosso app.
- Criar a landing page dentro do projeto e publicar na URL temporaria.
- Validar com primeiros usuarios antes de comprar dominio.

## Depende ou fica melhor com dominio proprio

- Ter uma URL profissional para vender, exemplo `adsmanagerai.com`.
- Melhorar confianca do cliente na landing page e checkout.
- Configurar emails profissionais do produto.
- Configurar callbacks finais e URLs publicas definitivas em Clerk, Meta, Stripe e Shopify.
- Pedir revisao/validacao mais profissional em plataformas externas.
- Criar links compartilhaveis de relatorios com marca propria.

## Configuracao tecnica

- Comprar e apontar dominio para a hospedagem do app.
- Configurar URLs de producao no Clerk.
- Configurar URLs de redirect/callback no Meta Developers.
- Configurar webhooks de Stripe em producao.
- Configurar webhooks de Shopify, quando a integracao estiver ativa.
- Trocar tokens temporarios da Meta por token longo ou System User Token.
- Revisar variaveis de ambiente de producao.
- Ativar monitoramento de erros e logs.

## Produto e venda

- Criar landing page publica com promessa clara do produto.
- Criar planos, limites e comparacao de recursos.
- Criar onboarding guiado para novo cliente conectar Meta, Stripe/Payhip e Shopify.
- Criar documentacao simples com passo a passo de conexao.
- Criar emails basicos: boas-vindas, teste gratis, pagamento, alerta e relatorio.

## Confianca dos dados

- Mostrar receita real vinda de checkout/pagamentos como fonte financeira principal.
- Manter eventos da Meta como dado de atribuicao e diagnostico, nao como verdade financeira.
- Explicar para o cliente que Meta pode contar eventos de pixel diferentes de vendas pagas.
- Criar auditoria de divergencia: Meta events vs vendas reais.

## IA e diferencial

- Criar contexto do negocio: publico, produto, oferta, margem, objetivo, tom da marca.
- Criar base de conhecimento interna com documentos de marketing, vendas e criativos.
- Permitir usuario master editar prompts, criterios de analise e modelos de relatorio.
- Criar mais de um layout de relatorio para o cliente escolher.
- Criar analises separadas para anuncios, criativos, produtos, site e funil.
